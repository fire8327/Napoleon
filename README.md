# 🍰 Napoleon — Кафе-кондитерская (Канаш)

Современный, премиальный и минималистичный лендинг для кафе-кондитерской **«Napoleon»** (г. Канаш, просп. Ленина, 26).

Сайт разработан с акцентом на эстетику светлого европейского пространства (*«атмосфера Pinterest»*), реальные фотографии кондитерской, живые отзывы гостей с Яндекс Карт и удобный интерактивный функционал для заказа тортов.

---

## ✨ Ключевые особенности и фичи

1. **Дизайн в стиле French & Scandi Chic:**
   - Палитра: тёплый фарфор, крем, лен, глубокий эспрессо и благородное шампанское золото.
   - Изысканная типографика: `Playfair Display` для заголовков и `Plus Jakarta Sans` для интерфейса.
   - Glassmorphism, микроанимации при скролле и интерактивные карточки с эффектом парения.

2. **Индикатор работы в реальном времени:**
   - Автоматически рассчитывает текущее время и показывает пульсирующий бейдж:
     - `Сейчас открыто • до 19:00` (если сейчас с 10:00 до 19:00)
     - `Закрыто • откроется в 10:00` (в нерабочее время).

3. **Интерактивная витрина с фильтрацией категорий:**
   - Фильтры: *Фирменные торты*, *Порционные десерты*, *Выпечка и вафли*, *Сытные боулы (поке)*, *Чайная карта*.
   - Реальные цены, порции, описания и фотографии из заведения.

4. **Интерактивный конструктор праздничного торта:**
   - Выбор повода (День рождения, Юбилей, Свадьба, Детский праздник).
   - Выбор начинки (Наполеон, Медовик, Молочная девочка, Красный бархат, Сникерс и др.).
   - Выбор веса и декора (ягоды, шоколад, крем, топперы).
   - **Живая индивидуальная надпись** с мгновенным отображением на визуальном макете торта.
   - Динамический расчет стоимости и кнопка отправки готового сформированного заказа напрямую в **WhatsApp** / звонок кондитеру.

5. **Фотогалерея интерьера с Lightbox:**
   - Аутентичные фотографии светлого зала с молдингами, витрин, праздничных упаковок и десертов.
   - Полноэкранный просмотр фото по клику с поддержкой клавиши `Esc`.

6. **Блок доверия и реальные отзывы:**
   - Официальный рейтинг **4.4 ★** с прямой ссылкой на Яндекс Карты.
   - Цитаты реальных гостей с акцентом на чистоту, свежесть десертов и атмосферу.

7. **Локация и контакты:**
   - Точный адрес: Канаш, проспект Ленина, 26.
   - Интерактивная карта Яндекс с меткой.
   - Кнопки для построения маршрута, прямого звонка и связи в мессенджерах.

---

## 🚀 Запуск проекта локально

У проекта нулевые внешние зависимости:

```bash
# Запуск через npm
npm start

# Либо напрямую через Node.js:
node server.js
```

После запуска откройте в браузере: **`http://localhost:3000`** (или просто откройте `index.html` в любом браузере).
